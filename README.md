# BEYOND · 屏幕之外

把显示器当作一扇通向虚拟空间的窗户。摄像头估算双眼位置，通过非对称视锥让屏幕边框保持固定，让深处的物体随视点产生运动视差，露出原本被边缘挡住的部分。

## 运行

需要 Node.js 22.12+（推荐 Node.js 24）。

```sh
npm ci
npm run dev
```

打开终端显示的 localhost 地址。首次开启摄像头后面向屏幕，点击「校准中心」，再左右、上下轻移头部。相机 Z 距离和焦距固定，前后移动不再驱动缩放。关闭摄像头或切回鼠标预览会立即停止摄像头视频轨道。

「九点视线校准」会在当前页面依次显示 9 个注视目标。保持头部相对稳定，用眼睛注视圆点，每个点自动采样约一秒，眨眼或丢失人脸时暂停。完成后显示估计的页面像素落点，以及从当前虚拟眼睛穿过该像素在屏幕平面上的位置、继续射入场景的单位射线和命中标记。头部平移仍负责真实窗口视差，眼球转动不被误当成头部位移。

- 鼠标移动：模拟眼睛在屏幕前的位置。
- 方向键：聚焦 3D 区域后移动视点。
- R：复位 / 重新校准头部中心。
- F：全屏 / 退出全屏。
- 两个空间、视差强度调整、摄像头画面预览均可直接操作。

## 实现

- Three.js：程序化展厅、雕塑、深空场景、实时光照和阴影。
- MediaPipe Face Landmarker：478 个面部/虹膜特征点和面部变换矩阵。眼角中心提供 X/Y 平移；归一化的虹膜相对眼角位移、yaw/pitch 和面部位置经个人九点岭回归映射到页面坐标。眨眼、虹膜缺失、大幅转头时暂停视线估计。
- 相机 Z 固定为 6，平移增益使用中心校准时的固定眼间距。One Euro 滤波降低抖动；离轴投影不对场景中心执行 `lookAt`。视线射线为 `normalize(screenPoint - virtualEye)`，无折射假设。
- 追踪模型与 WASM 文件随网站一起提供。视频只在浏览器本机处理，不发送到服务器、不录制。摄像头仅在用户主动点击后请求权限。
- 需要 HTTPS 或 localhost；无摄像头、拒绝授权、设备占用、人脸暂时丢失、WebGL 不可用时有对应反馈。GPU 追踪失败时尝试 CPU。

这是单目摄像头的相对位置与视线估计，不是专用眼动仪。MediaPipe 不直接提供注视点或经过测量的光学视轴；这里通过个人校准估计页面 CSS 像素落点，再构造数学上一致的虚拟射线。显示的「校准拟合误差」是校准数据残差，不代表实际注视精度。窗口尺寸变化会使视线校准失效，关闭摄像头即清除校准数据。坐姿、光照、头部角度、镜片反光改变后应重新校准。默认屏幕尺寸与观看距离是近似值。普通显示器提供运动视差，不提供双眼立体成像；定焦在这里表示固定虚拟投影距离和焦距。

## 验证与构建

```sh
npm test
npm run build
npm run preview
```

测试覆盖固定屏幕平面、遮挡显露、前后距离不影响相机与平移增益、射线与屏幕像素的一致性、虹膜和头部特征分离、平移/缩放不变性、眨眼门控、九点映射与无效校准拒绝、滤波失追重置。构建产物位于 `dist/`，可托管为静态网站。
